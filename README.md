# Python Library Management System

**Python · OOP · File I/O · Debugging · Testing**

A three-person academic Python project for managing a library catalogue through a command-line interface.

## What it does
- Load and save book records
- View the catalogue
- Borrow and return books
- Search by ISBN
- Add/remove books in librarian mode
- Run repeatable Book-model checks

## Portfolio refresh
I cleaned up the CLI flow, fixed the original catalogue filename/save scope issue, added a sample `books.csv`, and converted the model checks to assertions.

## Run
```bash
python library_app.py
```
